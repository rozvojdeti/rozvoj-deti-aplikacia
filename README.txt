ROZVOJ DETÍ S POROZUMENÍM – PRVÁ UKÁŽKOVÁ VERZIA

Toto je prvý vizuálny základ samostatnej PWA aplikácie. Obsahuje responzívnu domovskú stránku,
prehľad tém, ukážkové články a základné PWA súbory.

DÔLEŽITÉ:
- Zatiaľ nejde o hotový publikačný systém.
- Administrácia, bezpečné prihlásenie, databáza článkov a súkromná poradňa ešte nie sú pripojené.
- Ukážkové články sú ilustračné a pred zverejnením ich treba nahradiť schváleným obsahom.
- Súčasný web na Netlify sa týmto balíkom nemení.

ĎALŠÍ KROK:
Nahrať tento samostatný projekt do nového GitHub repozitára a nasadiť ho na samostatnú Netlify adresu.
Potom pripojíme databázu a zabezpečenú administráciu pre jediného správcu.
